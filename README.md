# ☯ 天道因果循环 (st-karma-cycle) — SillyTavern 扩展插件

> **“善恶终有报，天道好轮回。不是不报，时候未到。”**

这是一个专为 **SillyTavern（酒馆）** 打造的角色善恶因果账本与延时报应/福报触发扩展插件。它能自动结合**正文剧情**与**世界书（World Info）/角色卡设定**，识别各角色种下的善因与恶果，并通过**“天道轮盘（延时概率清算）”**机制，在几回合后的合适时机暗中向 AI 注入【天道因果清算指令】，让角色遭遇极其贴合前文的报应反噬或天赐机缘。

---

## 📦 安装方法

将本文件夹 `st-karma-cycle` 完整复制放入你的酒馆扩展目录（二选一即可）：

1. **全局第三方扩展目录**：
   `SillyTavern/public/scripts/extensions/third-party/st-karma-cycle/`
2. **用户数据扩展目录（推荐，更新酒馆不丢失）**：
   `SillyTavern/data/default-user/extensions/st-karma-cycle/`

放入后，刷新酒馆网页，在顶部 **扩展（积木图标）** 面板中即可看到 **☯ 天道因果循环 (Karma Cycle)**，右下角也会出现一个 `☯` 悬浮球。

---

## ✨ 核心机制说明

### 1. 混合判定引擎（省流 + 精准兼顾）
支持三种模式随时切换：
- **混合模式（默认推荐）**：
  - 自动在提示词末尾附带轻量协议，让主模型在每次回复最底部输出 `<karma>[{"char":"...","delta":-20,"deed":"...","rule":"...","delay":3}]</karma>`，插件拦截解析后自动从正文中剥离隐藏（**零额外 API 调用消耗**）。
  - 若主模型某回合未输出标签，则自动由后台静默 API 结合世界书兜底分析。
- **仅正文内嵌 `<karma>` 标签**：纯靠主模型顺带输出，完全不产生第二次请求。
- **仅后台静默 API 独立判定**：完全不干扰主模型正文格式，每隔 $N$ 回合在后台静默调用酒馆当前 API（或你在插件内单独配置的便宜副模型 API，如 `gpt-4o-mini` / `deepseek-chat`）结合世界书专门评判。

### 2. 世界书（World Info）与背景宿命扫描
- **世界书法则参考**：自动提取当前角色绑定的世界书、聊天世界书及全局世界书中包含 `因果,天道,善恶,报应,功德,业力,禁忌,戒律,门规,法则` 等关键词的条目作为判官依据（例如修仙世界破门规、克苏鲁世界触犯禁忌、武侠世界背信弃义）。
- **开局背景宿命扫描**：点击生死簿面板顶部的 **「🔍 扫描世界书与背景宿命」**，插件会直接阅读角色卡与世界书设定，把角色在背景故事里犯下的旧恶或旧善举提取为初始的“未结因果旧账”。

### 3. 天道轮盘 · 延时清算（“不是不报，时候未到”）
每次角色行善或作恶并不会立刻现世报，而是生成一枚带有 **潜伏期（默认 3 回合）** 的 **【因果引子（Causal Seed）】**：
1. **潜伏酝酿期**：刚做完坏事的前几回合，因果引子处于 `[⏳潜伏中]` 状态，不会触发报应，让剧情自然推进。
2. **成熟入池期**：度过潜伏期后，引子变为 `[🔥已成熟待报]`，计入该角色的成熟恶业/善功池。
3. **动态轮盘概率公式**：当成熟未结因果达到起转阈值（默认 `25` 点）且不在冷却期时，每回合自动投掷 `1d100`，触发概率随**业力深重程度**与**拖延回合数**递增：
   $$P(\text{触发}) = \min\Big(100\%,\; \text{基础概率} + (|\text{成熟因果}| - \text{阈值}) \times \text{因果权重} + \text{拖延回合数} \times \text{时间权重}\Big)$$
4. **旧账翻出与精准回旋镖**：一旦轮盘命中（或你在生死簿面板点击 **「⚡立即降下恶报 / ✨立即赐予福报」**），插件会把该角色具体在哪几回合做过什么事（如：`「第2回合：暗中克扣赈灾银两」「第5回合：嫁祸同门师弟」`）打包成一条 **【☯ 天道因果清算指令】** 注入下一轮生成，让 AI 写出前后呼应的宿命回旋镖！
