# 因果回响 (Karma Echo) — SillyTavern 扩展插件

> **“凡有所为，皆有回响 · 延时因果与剧情回旋镖追踪”**

这是一个面向 **SillyTavern（酒馆）** 的全题材因果追踪与延时报应/回馈扩展插件。界面采用**新中式极简 × 现代半透明毛玻璃仪表盘**风格（墨石蓝底、天青玉、绛朱砂、暮山紫低饱和矿物色），文案与导演指令完全去修仙中二化，无论是现代都市、职场悬疑、校园日常、西幻还是古风题材都能自然融入、绝不出戏。

---

## 📦 安装方法

在酒馆顶部 **扩展（积木图标）** → **安装扩展 (Install extension)** 中填入仓库地址：

```text
https://github.com/Wellilam/st-karma-cycle
```

## ✨ 核心机制说明

### 1. 混合识别与世界书（World Info）联动
- **混合模式（默认）**：自动引导主模型在正文末尾输出隐藏的 `<karma>[...]</karma>` 标签，解析后自动剥离隐藏（**零额外 API 调用**）；若主模型某回合未附带标签，则按间隔由后台静默 API 兜底分析。
- **每回合判定**：直接使用酒馆本轮生成时**实际激活**的世界书条目（由世界书自己的关键词/常驻规则触发，和主模型看到的一致），连同剧情一起交给 LLM 理解判断，无需配置任何关键词。
- **开局扫描「扫描世界书与前史」**：把所有已启用世界书的全部条目 + 角色卡整体交给 LLM 通读，由模型自己找出角色前史中的未了恩怨、亏欠与恩情，生成初始因果伏笔（字数上限可在设置中调整）。
- **支持独立副模型 API**：可单独配置轻量 OpenAI 兼容接口专门负责后台分析。

### 2. 延时概率检定（剧情回旋镖）
每次显著的正向或负面行为都会生成一枚带有 **潜伏期（默认 3 回合）** 的 **因果伏笔**：
1. **潜伏酝酿期**：事件刚发生后的前几回合处于潜伏状态，不立即现世报，让剧情自然铺垫。
2. **成熟入池期**：潜伏期满后进入待触发池；当累积值达到起检阈值（默认 `±25`）且不在冷却期内时，每回合自动执行概率检定：
   $$P(\text{触发}) = \min\Big(100\%,\; \text{基础触发率} + (|\text{成熟分值}| - \text{阈值}) \times \text{分值权重} + \text{拖延回合数} \times \text{每回合递增率}\Big)$$
3. **前后呼应的剧情触发**：检定命中（或在卡片上手动点击 **「触发报应 / 触发回馈」**）后，插件会将该角色过往具体的因果伏笔打包注入下一轮生成，让 AI 按照当前故事原本的世界观逻辑写出自然贴切的回旋镖剧情。
